# CompTIA Network+ Practice Diagnostic Questions

Targeted review questions covering security defense, port assignments, wireless propagation, troubleshooting methodology, and network addressing anomalies.

---

### Question 1: Active Intrusion Countermeasures
Which device inspects active network traffic streams in real-time and automatically blocks detected malicious packets inline?
- [ ] A. VPN Gateway
- [x] **B. IPS (Intrusion Prevention System)**
- [ ] C. Packet Filter
- [ ] D. Proxy Server

> [!tip] Rationale
> An Intrusion Prevention System (IPS) sits directly in the active data path and drops malicious frames in real-time, whereas an IDS only logs or alerts passively.
