# Cloud Computing Course Overview & Fundamentals

Foundational framework for Semester 5 Cloud Computing, addressing the evolution from bare-metal colocation to multi-tenant virtualized cloud fabrics.

> [!info] Course Trajectory
> Exploration of virtualization layers, Software-Defined Networking (SDN), distributed storage consistency models, container orchestration, and serverless compute primitives.

---

## 1. Technological Transition
Traditional on-premises data centers bound organizations to rigid procurement lifecycles, excess idle capacity provisioning, and manual hardware lifecycle management. Modern distributed cloud computing decouples application workloads from physical silicon through hypervisors and kernel namespace virtualization (cgroups/namespaces).

## 2. Fundamental Service Tiers
1. **Infrastructure as a Service (IaaS)**: Raw compute instances, block storage, and virtual network routing (e.g., AWS EC2, GCP Compute Engine).
2. **Platform as a Service (PaaS)**: Managed runtime runtimes, serverless functions, and automated database scaling without operating system administration (e.g., AWS Elastic Beanstalk, Vercel).
3. **Software as a Service (SaaS)**: Complete end-user software applications delivered over browser interfaces (e.g., Google Workspace, Microsoft 365).
