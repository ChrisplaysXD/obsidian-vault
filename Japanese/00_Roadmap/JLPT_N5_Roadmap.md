# 🎯 JLPT N5 Milestone Roadmap

> [!NOTE] Level Profile
> N5 tests basic sentence mechanics, ~800 core words, ~100 kanji characters, and beginner conversational dialogues spoken slowly with clear articulation.

---

## 📚 Core Grammar Checkpoints
- [ ] Particles: `は` (topic) vs `が` (subject identifier)
- [ ] Particles: `に` (specific time, destination, indirect object) vs `で` (location of action, means)
- [ ] Particles: `を` (direct object), `と` (and, with), `も` (also), `の` (possession)
- [ ] Copula: `だ` / `です` (affirmative), `じゃない` / `ではありません` (negative)
- [ ] Polite verb forms: `〜ます`, `〜ません`, `〜ました`, `〜ませんでした`
- [ ] Te-form (`〜て`): Connecting actions, requests (`〜てください`), progressive (`〜ている`)
- [ ] Desires: `〜たい` (want to do), `〜ほしい` (want an object)
- [ ] Adjectives: I-adjectives (`大きい`, `高くない`) vs Na-adjectives (`静か`, `きれい`)
- [ ] Comparison: `A のほうが B より...` (A is more ... than B)
- [ ] Numbers, counters (`つ`, `人`, `本`, `枚`, `杯`), and telling time (`時`, `分`)
